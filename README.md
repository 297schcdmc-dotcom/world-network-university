# World Network University (WNU)

> **Knowledge without borders.**

World Network University is an experimental, open-source project exploring what a structured, global, web-native learning institution could look like.

## Current status

**Public Alpha**

The project currently contains the first experimental course pathway:

- **SOCI 101 — Sociology 101**
- Sociological Theory
- Culture & Socialisation
- Class & Social Stratification
- Gender, Sex & Gender Inequality
- Race, Ethnicity & Racism

## Project goals

WNU aims to develop an accessible learning platform with structured courses, interactive assessment, progress tracking, multilingual learning, and an open contribution model.

## Roadmap

1. Public static prototype
2. Student accounts and cloud database
3. Course publishing architecture
4. Contributor and instructor system
5. Transcripts / learning records
6. Multilingual support
7. Public beta

## Important status notice

World Network University is currently an experimental learning-platform project. It is **not an accredited higher-education provider** and does **not award recognised university degrees**.
