# Contributing to World Network University

Thank you for your interest in WNU.

## Ways to contribute

You can contribute by:

- fixing bugs or accessibility problems;
- improving the website interface;
- proposing new learning features;
- improving existing educational material;
- proposing new courses or modules;
- improving translations and multilingual support;
- improving documentation.

## Course contributions

Course proposals should clearly state:

1. course title and code;
2. intended learners;
3. learning outcomes;
4. module structure;
5. sources or evidence base;
6. assessment approach;
7. licensing status of submitted material.

Do not submit copyrighted course material that you do not have permission to redistribute.

## Development workflow

Fork the repository, make focused changes, and submit a pull request explaining what you changed and why.

WNU is currently an experimental project. Contribution rules will become more formal as the project develops.
